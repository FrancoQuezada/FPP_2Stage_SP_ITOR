\begin{abstract}
Firebreak placement under uncertain ignition and propagation is a stochastic
network decision problem. Directed Cell2Fire scenario graphs retain alternative
fire routes but make optimization with many scenarios costly. We consider a
rooted shortest-path tree of each original Reburn graph for optimization,
followed by evaluation of the selected placement on its paired original
graph. The scenario recourse is characterized by reachability, giving an
optimal binary burn vector and relatively complete recourse. We derive
downstream, capped-coverage and propagation-path lower bounds and show that
the complete coverage and path projections coincide with fractional recourse
on rooted trees. An exact Branch-and-Benders implementation supports expected
loss, CVaR and mean--CVaR; a matched evaluation protocol separates solver
performance, paired graph discrepancy and out-of-sample behavior. The
repository snapshot available for this revision has no nonempty final run
data, so the computational benefit and decision quality of the reduction
remain empirical questions.
\end{abstract}
