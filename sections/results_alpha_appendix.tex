\section{Detailed computational statistics}\label{app:alpha}

\subsection{Reduced-panel statistics by budget}

Each row below uses all 15 reduced \texttt{new20x20} runs for one
objective, method and budget: five replications at each of
$n=100,200,400$. Gap columns are percentages; time columns are seconds.
$N_{\rm opt}$ counts runs resolved to relative gap $10^{-3}$.
SD denotes the sample standard deviation, with denominator $15-1$.
Positive certified gaps and recorded time-limit overruns are retained.
These tables use the same source and reproduction script as
Table~\ref{tab:new20-gaps-times}. The generated file
\texttt{tables/new20\_statistics.csv} additionally records statistics
for every five-run $(\alpha,n)$ block, enabling the within-size
checks discussed in Section~\ref{sec:results}.
